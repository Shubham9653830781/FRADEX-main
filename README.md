# FRADEX — American Express Strategy Challenge 2024

**Project summary**  
FRADEX is a data-driven project created for the *American Express Strategy Challenge 2024*. The goal is to identify and flag individuals with a high risk of loan fraud using exploratory data analysis, clustering, and classification techniques. The primary artifact is a Jupyter notebook (`Amex.ipynb`) that performs preprocessing, EDA, feature engineering, modeling, and evaluation.

---

## Key results
- Performed EDA on a banking dataset with 61 features.
- Built clustering and classification pipelines that achieved **~0.98 F1 score** on the validation set (final notebook contains details and metrics).
- Notebook contains reproducible steps, visualizations, and interpretation.
